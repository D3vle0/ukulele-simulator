## Features

- ⚡ **Zero-Latency Audio**: Web Audio API audio buffer preloading eliminates any first-hit loading delays.
- 🎸 **Interactive Fretboard Visualization**: Realistic 1~8 fret instrument neck, 4 strings, inlay dots, and real-time key glow feedback.
- 🎵 **Real-time Chord Recognition**: Automatically detects and displays chords (C, G, Am, F, E7, etc.) based on your fingering.
- ✨ **String Vibration Animation**: Visual string vibrations and sound wave pulses when strumming or plucking.
- 🇰🇷 **Bilingual Keyboard Mapping**: Seamlessly works in both English and Korean IME modes.
- 🖱️ **Mouse & Touch Friendly**: Click any fret or quick preset chord buttons to play.
- 🎼 **High-G / Low-G Tuning Toggle**.

## How to play

Your keyboard is a ukulele fretboard and strings.

### Fretboard

- **1st string (A)**: `1`, `2`, `3`, `4`, `5`, `6`, `7`, `8`
- **2nd string (E)**: `q`, `w`, `e`, `r`, `t`
- **3rd string (C)**: `a`, `s`, `d`, `f`, `g`
- **4th string (G)**: `z`, `x`, `c`, `v`

### Stroke

- Press <kbd>Space</kbd> to downstroke.

### Play single string (Pluck)

- **1st string**: `0`, `-`, `=`
- **2nd string**: `o`, `p`, `[`
- **3rd string**: `k`, `l`, `;`, `'`
- **4th string**: `m`, `,`, `.`

### Example

- **G chord**: Press <kbd>Space</kbd> while holding `2`, `e`, `s`.
- **C chord**: Press <kbd>Space</kbd> while holding `3`.
- **Am chord**: Press <kbd>Space</kbd> while holding `x`.
- **F chord**: Press <kbd>Space</kbd> while holding `x`, `q`.
- **E7 chord**: Press <kbd>Space</kbd> while holding `z`, `s`, `2`.
