## 주요 기능

- ⚡ **지연 시간 없는 즉각 재생 (Zero-Latency)**: Web Audio API 기반 오디오 버퍼 사전 로딩으로 첫 음부터 지연 없이 즉시 소리가 납니다.
- 🎸 **우쿨렐레 프렛보드 실시간 시각화**: 1~8 프렛, 4개 줄, 인레이 도트, 누르고 있는 키와 연주 중인 음을 한눈에 시각적으로 보여줍니다.
- 🎵 **실시간 코드(Chord) 감지**: 현재 운지한 상태를 분석하여 C, G, Am, F, E7 등의 코드를 자동으로 인식해 표시합니다.
- ✨ **스트링 진동 애니메이션 & 피드백**: 스트로크 및 줄 뜯기 시 실제 악기 줄이 진동하는 물리 애니메이션이 적용됩니다.
- 🇰🇷 **한글/영문 자판 자동 호환**: 한글 입력 상태에서도 키보드 모드 변경 없이 바로 연주할 수 있습니다.
- 🖱️ **마우스/터치 지원 & 추천 코드 가이드**: 프렛을 직접 클릭하거나 상단 추천 코드 버튼을 눌러 원클릭으로 운지 및 시범 연주가 가능합니다.
- 🎼 **High-G / Low-G 튜닝 전환 지원**.

## 사용법

키보드가 우쿨렐레 지판과 줄이라고 생각하면 됩니다.

### 프렛보드 운지

- **1번 줄 (A)**: `1`, `2`, `3`, `4`, `5`, `6`, `7`, `8`
- **2번 줄 (E)**: `q`, `w`, `e`, `r`, `t`
- **3번 줄 (C)**: `a`, `s`, `d`, `f`, `g`
- **4번 줄 (G)**: `z`, `x`, `c`, `v`

### 스트로크

- **다운 스트로크 (Down)**: <kbd>Space</kbd> 키를 눌러 다운 스트로크를 연주하세요.
- **업 스트로크 (Up)**: <kbd>Shift</kbd> + <kbd>Space</kbd> 또는 <kbd>Enter</kbd> 키를 눌러 업 스트로크를 연주하세요.
- **마우스 연주**: 사운드홀 영역을 마우스로 위아래로 쓸어내려 실제 악기처럼 스트로크할 수 있습니다.

### 각각의 줄 단음 연주 (뜯기)

- **1번 줄**: `0`, `-`, `=`
- **2번 줄**: `o`, `p`, `[`
- **3번 줄**: `k`, `l`, `;`, `'`
- **4번 줄**: `m`, `,`, `.`

### 예시

- **G 코드**: `2`, `e`, `s` 를 누른 채로 <kbd>Space</kbd> 를 누르세요.
- **C 코드**: `3` 을 누른 채로 <kbd>Space</kbd> 를 누르세요.
- **Am 코드**: `x` 를 누른 채로 <kbd>Space</kbd> 를 누르세요.
- **F 코드**: `x`, `q` 를 누른 채로 <kbd>Space</kbd> 를 누르세요.
- **E7 코드**: `z`, `s`, `2` 를 누른 채로 <kbd>Space</kbd> 를 누르세요.

## 시작하기

`index.html` 파일을 브라우저로 열거나 로컬 웹 서버를 실행하여 바로 연주할 수 있습니다.
